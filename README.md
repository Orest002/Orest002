## `> whoami`

I'm **Əliəsgər Fətullayev** — a cybersecurity student and offensive-security researcher based in **Baku, Azerbaijan**, focused on **web application exploitation, Active Directory attack paths, and Linux privilege escalation**.

My approach is simple: **understand a system deeply enough to break it cleanly, document it precisely enough that the fix is undeniable, and automate everything worth repeating.** Every lab I run and every bug I chase turns into a tool, a write-up, or both.

I'm also the **founder of [Vision Voice Assist](https://visionvoiceassist.netlify.app)** — AI-powered assistive glasses that give sight a voice. It taught me how real systems are built end-to-end; offensive security taught me how they fall apart. I want to spend my career on the second half — and I'm building toward **eJPT → CPTS → OSCP** to prove it.

> *"hack the planet. then document it properly."*
